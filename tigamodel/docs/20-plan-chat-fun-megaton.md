# 20 — แผนทำ TIGA CHAT ให้ "สนุกอีกหนึ่งล้านเท่า" (เจ้าของสั่ง 2026-10-03)

ต่อจากเอกสาร 19 (`19-plan-chat-fun-and-teaching.md`) ซึ่งทำไป **7 จาก 8 เฟส**
แผนนี้ตอบคำถามเดียว: **อะไรทำให้แชท "สนุก" จริงๆ** — ไม่ใช่เพิ่มลูกเล่นธรรมดา

> กติกาของเอกสารนี้: **ทุกข้อต้องผูกกับตัวเลขที่วัดได้** และ **ห้ามอ้างว่าสนุกขึ้นถ้ายังพิสูจน์ไม่ได้**
> ตรงกับสไตล์ที่ผ่านมา: ห้ามแต่งตัวเลข · ห้ามเปิดสวิตช์เอง · ห้ามขายเหรียน/เพชร · "what chat pays is an owner decision"

## 0. บทสรุปสำหรับเจ้าของ (อ่านข้อนี้ก่อน ข้ออื่นยาว)

**คำถาม: ทำแผน 19 เสร็จไหม** → **เสร็จ 7/8** (ดูตาราง §1) · เหลือเฟส 3 ที่ต้องคุณเปิดสวิตช์เอง และเฟส 7 (ปิดรั่วต้นทุน) ยังไม่เริ่ม

**คำถาม: แชทตอนนี้ "สนุก"แค่ไหน** → มีของดีอยู่ 4 อย่าง (ครูถามกลับ · แถบคืบหน้า · EXP · ปุ่มลงมือทำ)
แต่วัดแล้วพบว่า **มันยังไม่ใช่เกม** เพราะ:

| สิ่งที่ผู้เรียนเห็น | สถานะจริง | ทำไมจึง "ยังไม่สนุก" |
|---|---|---|
| `🔥 streak` ในแถบคืบหน้า | **เป็น streak ของการฝึกทั้งแอป** (`profile.streak`) ไม่ใช่ของการถาม | ครูถามมา 3 วัน แต่แถบบอกว่า "7 วันต่อเนื่อง" เพราะไปเล่นเพลง — **ผิดสิ่งที่ถาม** |
| ครูถามกลับ (`[? ...]`) | ทำแล้ว แต่ **ครูไม่มีตัวตนที่เปลี่ยนไปตามผลลัพธ์** | ถามมากแค่ไหนก็ครูคนเดิมตอบเหมือนเดิม — ไม่มีอะไรให้ "อยากคุยต่อ" |
| EXP 10 ต่อคำถาม | จ่ายแล้ว แต่ **ไม่มีอะไรให้เล่นกับ EXP ที่ได้** | ได้ตัวเลขมาแล้วเงียบไป ไม่มีการเติบโต ไม่มีเป้า ไม่มีอันดับ |
| ตอบถูก/ผิดใน `AskRow` | บันทึกลง `recordMemory()` แล้ว | **ไม่มีอะไรตอบกลับผู้เรียนทันที** — ไม่มีเสียง ไม่มีขยับ ไม่มีอะไรบอกว่า "เจ้าเก่งมาก" |

**แกนของแผนนี้ (1 ประโยค):** ทำให้ **การถาม** เป็นกิจกรรมที่มีความต่อเนื่องของตัวเอง —
มี streak ของตัวเอง · มีครูที่โตไปตามความพยายาม · มีตัวเลขที่เติบโต · มีปฏิกิริยาทันทีทุกครั้งที่ทำถูก

## 2. ช่องรั่ว 5 อันที่ทำให้แชท "ไม่สนุก" (วัดได้ ไม่ใช่ความรู้สึก)

### รั่ว #1 · แถบคืบหน้าบอกผิดตัวเลข — `App.tsx` (`chatProg`)

```js
streak: (profile && profile.streak) || 0,   // ← streak ของการฝึกทั้งแอป
```
ผู้เรียนที่ถามครูมาต่อเนื่อง 10 วัน แต่ไม่ได้เล่นเพลงเลย จะเห็น `🔥 0`
และคนที่เล่นเพลงทุกวันจะเห็น `🔥 30` ทั้งที่ไม่เคยถามครูเลย

**ต้นทุนการแก้: 0** · ไม่ต้องเรียก server · เก็บใน `tg_chat_stats` ที่มีอยู่แล้ว
**ผลที่วัดได้: ตัวเลขบนแถวตรงกับสิ่งที่ผู้เรียนทำในแชทจริง 100%**

### รั่ว #2 · `tg_chat_stats` เก็บแค่ 2 ตัวเลข (`use-chat.ts:141`)

```js
return (s && s.d === d) ? s : { d, asked: 0, exp: 0 };   // ← มีแค่นี้
```
ไม่มี streak · ไม่มีจำนวนถามถูก · ไม่มีครูที่โต · **ข้อมูลที่ควรขับเกมยังไม่ถูกเก็บเลย**
แปลว่า "ทำเกมให้สนุก" ตอนนี้ทำไม่ได้จริง เพราะ **ไม่มีตัวเลขให้เล่น**

### รั่ว #3 · ตอบถูก = เงียบ (ไม่มีปฏิกิริยา)

`AskRow` (`chat-ui.tsx:150`) ตอนผู้เรียนกดคำตอบ:
เรียก `onMark()` → `recordMemory()` → **จบ ไม่มีอะไรเกิดขึ้นบนหน้าจอ**
เทียบกับ Play Along ที่มี judge word · สปาร์ก · เสียง · ดาว

**ต้นทุนการแก้: ~0** (CSS + สถานะชั่วคราว) · **ผลที่วัดได้: ผู้เรียนตอบถูกแล้วเห็นอะไรทันทีใน 200ms**

### รั่ว #4 · ครูไม่มีอันดับ ไม่มีการเติบโต

`EXP = { lesson: 50, chapter: 25, ask: 10, daily: 15 }` (`App.tsx:242`)
EXP มีอยู่ 4 ชนิด แต่ **แชทมี 1 ชนิด (ask) และไม่มีอะไรให้เล่นกับมันเลย**
ผู้เรียนถามครู 100 ครั้ง = 1,000 EXP = เงียบสนิท ไม่มีอันดับ ไม่มีเป้าหมาย ไม่มีอะไรให้ตั้งใจทำต่อ

### รั่ว #5 · รอบที่ 7 ยังไม่เริ่ม = แชทยังช้าและแพง

`measure-chat-cost.mjs` วัดได้ **ตอนนี้** (หลังแก้บั๊ก keyword):

| ตัวเลข | ค่า |
|---|---|
| KB ทั้งหมด | **17,246 รายการ / 1,960,702 ตัวอักษร** |
| ส่วนคงที่ส่งทุกคำถาม | **8,480 ตัวอักษร** |
| prompt กลางๆ | **49,248 ตัวอักษร** |
| แย่ที่สุด (`minor chord ต่างจาก major`) | **1,392,371 ตัวอักษร** = **28.3 เท่า** ของกลางๆ |
| เพดาน hot path | 8,000 |
| `withAiCache` ในแชท | **ไม่ถูกเรียกเลย** |

**ทำไมต้องปิดรั่วนี้ก่อนเพิ่มความสนุก:** ถ้าจะเพิ่มเกมในแชท ตัวเลขที่ส่งไปหาครูจะยิ่งใหญ่ขึ้น
ยิ่งคุยยาว ยิ่งแพง ยิ่งช้า ผู้เรียนก็ยิ่งเลิกคุย → **ความสนุกที่ไม่แก้ต้นทุน คือความสนุกที่ใช้ไม่ได้จริงบนมือถือ**

## 3. แกนของแผน: 5 กลไกที่ทำให้ "สนุก" (เรียงตามราคาต่อความสนุก)

### ★ กลไก 1 · **STREET OF QUESTIONS** — แก้รั่ว #1 + #2
> *"ถามครูติดกัน N วัน" เป็นของฉัน ไม่ใช่ของการฝึก*

- `tg_chat_stats` เพิ่ม `days: string[]` (วันที่ถามจริง เก็บแค่ 30 วันล่าสุด)
- streak ของแชต = **จำนวนวันต่อเนื่องที่ `asked ≥ 1`** — ไม่ใช่ `profile.streak`
- `ChatProgress` แสดง streak ของแชต · แถบเดิม (streak การฝึก) ย้ายไปอยู่หน้าโปรไฟล์ซึ่งเป็นที่ถูกของมัน
- เมื่อ streak ครบ 3 / 7 / 14 / 30 วัน → ขึ้น "เหรียญ" (badge) ที่มีอยู่แล้วใน `BADGES` (`App.tsx:411`)

**พิสูจน์ด้วย:** smoke ใหม่ 20+ เช็ก · ตัวเลขบนแถวตรงกับลำดับวันที่ถามจริงทุกกรณี (มี `profile.streak` ปนมาก็ยังถูก)
**ต้นทุน:** 0 · **ผล:** แถบที่ผู้เรียนมองทุกวันเปลี่ยนจาก "ตัวเลขของคนอื่น" เป็น "ของฉัน"

---

### ★ กลไก 2 · **REACTION** — แก้รั่ว #3
> *ตอบถูกแล้ว "ได้เอา" ต้องเกิดขึ้นบนหน้าจอทันที*

ตอนกดคำตอบใน `AskRow`:
- **ถูก** → ตัวคำตอบเปลี่ยนเป็นเขียว + ย่อขึ้น + เครื่องหมาย ✓ ขึ้น (CSS 300ms) · เสียงสั้น ๆ 1 ครั้ง
- **ผิด** → สั่นเบา ๆ (2 ครั้ง ไม่เกิน 3 ครั้ง/วินาที ตามกฎ flash) · ครูอธิบายว่าทำไม
- **ทั้งสองกรณี** → แถบ EXP ขยับขึ้น 1 ครั้ง (ไม่ใช่ตัวเลขกระโดด แต่เป็น "+10" ที่ลอยขึ้นแล้วหาย)

**กฎเสียงตาม `AGENTS.md`:** เสียงใหม่ทุกตัวต้องเป็น **noise สูงเหนือเปียโน** หรือถูก blacklist ใน `_accMarkSuppress`
และมีเสียง mic-safe — เพราะ `AGENTS.md` เขียนไว้ว่าไมค์อ่านผิดโน้ตเป็นปัญหาจริงแล้ว
**พิสูจน์ด้วย:** `verify-playalong-mic-band.mjs` ต้องยังผ่าน (คอนเทนเนอร์นี้ไม่มี Chromium → ต้องรันบนเครื่องเจ้าของ)

### ★ กลไก 3 · **COACH RANKS** — แก้รั่ว #4
> *ครูคนเดิมตอบเหมือนเดิมทุกวัน — ทำให้ครูมีชีวิต*

ครูสะสม EXP จากการถามของผู้เรียน (`tg_chat_stats` เพิ่ม `coachXp`):

| แรงค์ | ต้องถามสะสม | หน้าตาครู |
|---|---|---|
| ผู้เริ่มต้น | 0 | ปกติ |
| ผู้ช่วย | 20 คำถาม | +จุด/ตาแว็บ |
| นักสอน | 60 คำถาม | +ช่องท้องยิ้ม |
| เซนเซอร์ | 150 คำถาม | +วงแหวนเรืองแสง |
| ที่ปรึกษา | 400 คำถาม | +ฮาโล |

**ข้อดีที่ไม่ได้คิดจากเรื่องคุณ:** มันทำให้ **ผู้เรียนอยากถามต่อ** ไม่ใช่แค่อยากได้ EXP
เหตุผลที่คนถามครูคืออยากรู้เรื่อง — ถ้าครูโตไปตามเวลา การถามจะรู้สึกเหมือน **การเลี้ยง** ไม่ใช่การใช้เครื่องมือ
**ความเสี่ยงที่ต้องระวัง:** ห้ามให้แรงค์ครูผูกกับการซื้อเงินจริงเด็ดขาด (กติกาห้ามขายเหรียน/เพชร) — ระบบนี้ไม่มีทางซื้อ จึงไม่ขัด

### ★ กลไก 4 · **MICRO-GAME ที่พิสูจน์ได้ว่าเป็นเกม** — หัวใจของคำว่า "สนุก"
> *ครูถามกลับแล้วผู้เรียนมีแค่ 3 ปุ่ม — เปลี่ยนให้เป็นเกมจริง*

เกม **"โน้ตตาคอย"** (note-ear) — ครูถาม "โน้ตอะไร" ผู้เรียนแตะคำตอบ
แต่เพิ่ม **การเสี่ยง/ผลตอบแทน** 3 ชั้นที่คำนวณได้ ไม่ใช่สุ่ม:

1. **โบนัสสาย** — ถ้าเฟสก่อนหน้าเคยตอบถูก → ตอบถูกได้ **EXP ×1.5**
   (ยิ่งถามต่อยิ่งคูณ แต่ **คำตอบผิดทำลายสายทั้งเส้น** → ความเสี่ยงจริง)
2. **ท้ายเวลา** — ตอบภายใน 8 วินาที → +50% · เกิน → ครูบอกให้คิด
3. **เลือกยากขึ้นเมื่อถามถูก** — ตอบถูก 2 ข้อติด → คำถามถัดไปยากขึ้นหนึ่งขั้น (ปุ่ม 4 → 6 → โน้ตซับซ้อน)

**ทำไมนี่ถึง "สนุก" และไม่ใช่แค่หรอย:** มันมี **ความต่อเนื่อง** — สถานะสายครูอยู่ข้ามคำถาม
แต่มัน **ไม่ใช่การพนันด้วยเงินจริง** และคิดจากการตอบถูดเดิมล้วน ๆ จึงตรวจสอบได้ (ตอบถูก → ต้องขึ้นสาย ตอบผิด → ต้องตก)

**พิสูจน์ด้วย:** smoke ใหม่ที่ **เล่นเกมจริง** ผ่าน `chat-coach.ts` ล้วน ๆ 50 ตัวอย่าง
ครอบคลุม: สายตก → กลับมาได้ · โบนัสคูณถูกต้อง · เวลาไม่มีผลกับคำตอบ · ยากขึ้นเฉพาะเมื่อถูก
