## 2. หลักการที่ใช้ตัดสินทุกข้อ ("ผู้ใหญ่และเด็กใช้หน้าเดียวกันได้")

1. **หนึ่งจอ หนึ่งคำถาม:** เห็นแล้วตอบได้ใน 3 วินาทีว่า "ตอนนี้ต้องทำอะไร" — ที่เหลืออยู่ในชั้นรอง
2. **ไม่มีอะไรบังปุ่มหลักและแท็บล่าง** ในทุกขนาดจอ 320–430 px
3. **ที่เดียวเรียงลำดับ popup:** มีคิวเดียว แสดงทีละอย่าง ไม่แสดงขณะผู้เรียนกำลังเล่น และไม่ทับปุ่มหลัก
4. **เห็น–ได้ยิน–ทำ–รู้สึก:** ทุกโน้ตสื่อสี่ทางพร้อมกัน (สี/ชื่อโด-เร-มี/นิ้ว/เสียง) ไม่พึ่งการอ่านอย่างเดียว
5. **ความหนาแน่นสองระดับ ไม่ใช่สองแอป:** "ง่าย" (ค่าตั้งต้น, โหมดเด็ก) และ "ละเอียด" (ผู้ใหญ่เปิดเอง: เปอร์เซ็นต์, เซ็นต์ที่เพี้ยน, จังหวะ) — ข้อมูลเดียวกัน แสดงต่างกัน
6. **ผิดคือโอกาสลอง ไม่ใช่คะแนนติดลบ** และไม่ตำหนิจากสิ่งที่เครื่องไม่แน่ใจ (ต่อจากแผน 27)

## 3. แผนงาน

### ระยะ A — ทำให้ "จอไม่พัง" (ก่อนอย่างอื่น · ทำได้ในครึ่งวัน · วัดผลด้วยบอตได้ทันที)
- **A1 Practice Mode พอดีหนึ่งจอ:** จัดเลย์เอาต์เป็น 3 ชั้นคงที่ (หัว / เวที / ท้าย); ชั้นเวทีรับพื้นที่ที่เหลือและย่อเปียโน มือ และจุดโน้ตตามความสูงจอ (320×568 ต้องเห็นครบโดยไม่เลื่อน); เนื้อหาไม่ถูกแถบล่างทับ (padding-bottom = ความสูงแถบ + safe-area)
- **A2 คิวป้ายเดียว (`OverlayQueue`):** toast EXP, การ์ดชวนไปท้าทาย, popup สอนอัตโนมัติ, ป้ายเตือนต่าง ๆ เข้าคิวเดียว: แสดงทีละอย่าง, หน่วงจนกว่าผู้เรียนอยู่ว่าง (ไม่ได้กำลังฝึก/เล่น), ตำแหน่งอยู่เหนือแท็บล่างและไม่ทับปุ่มหลัก, ป้ายที่ไม่เร่งด่วนหายเองใน 4 วินาที — ต่อยอดตรรกะ `atipDelivery` ที่มีอยู่แทนการเขียนใหม่
- **A3 ปุ่มซ้าย/ขวาเป็นปุ่มเดียวแบบสลับ:** ไอคอนมือชุดเดียว (ภาพมือที่ชี้นิ้วตัวเดียวกับที่ใช้ในหน้าฝึก) + คำว่า "ซ้าย"/"ขวา"
- **A4 ไมค์ไม่แน่ใจ ไม่เป็นตัวใหญ่สีแดง:** "Heard" ที่ไม่แน่ใจแสดงเป็นรูปหูสีเทาเล็ก; ตัวอักษรใหญ่ใช้เฉพาะเมื่อแน่ใจว่าเป็นการกดจริง
- **ตรวจ:** บอต Playwright ที่ 320/360/390/430 px × 3 ภาษา × โหมดเด็ก/ผู้ใหญ่ ตรวจว่า (ก) ไม่มี element ปุ่มหลักถูกทับ (ใช้ `elementFromPoint` ที่กึ่งกลางปุ่ม), (ข) ไม่มีเลื่อนแนวนอน, (ค) แถว "✓ n / N" มองเห็นเต็ม

### ระยะ B — หน้าครู AI ให้ตอบ "ตอนนี้ทำอะไร" ภายใน 3 วินาที
- **B1 โครงสามโซน:** (1) **ตอนนี้** = การ์ดเดียว (สิ่งที่จะฝึก · กี่โน้ต · ประมาณกี่นาที · ปุ่มใหญ่ "เริ่ม") ใช้ `learnerSignal().nextAction` ตัวเดียวกับ Daily Mentor (กฎ "ตัวตัดสินใจเดียว"); (2) **ลองเล่น** = เปียโน + ปุ่มซ้ายขวา + เล่นซ้ำ; (3) **ถามครู** = ช่องแชทพับเป็นแถบเดียว กดแล้วขยาย
- **B2 ของรอง** (อัด/ฟังเดโม/ตารางนิ้ว/สำรวจเพิ่ม) อยู่ใต้ "เพิ่มเติม" แบบพับ ตามกฎ "อย่าเพิ่มกล่องเหนือเส้นพับ" ของแผน 18
- **B3 ตารางนิ้วเป็นมือที่ไล่ไฟ:** แทนวงกลมแดง 8 วง ใช้ภาพมือเดียวกับหน้าฝึก ไฟวิ่งตามโน้ตที่เล่นเดโม
- **B4 ข้อความเรียงถูก:** หัวบล็อกไม่ตัดกลางประโยค (ใช้ข้อความสั้น "แตะเปียโนเพื่อเล่น")

### ระยะ C — ใช้ง่ายทั้งเด็กและผู้ใหญ่ด้วยกลไกเดียว
- **C1 สองระดับความหนาแน่น:** "ง่าย" (ค่าตั้งต้น และโหมดเด็ก) / "ละเอียด" (สวิตช์ในตั้งค่า: แสดงเปอร์เซ็นต์ความแม่นยำ, เซ็นต์ที่เพี้ยน, ค่าจังหวะ, ตัวเลขนิ้วเต็ม) — โหมดเด็กที่ปล่อยแล้ว (`.kid`) คือระดับ "ง่าย" + คำสั้น; ผู้ใหญ่เลือก "ละเอียด" ได้
- **C2 ชื่อโน้ตตามภาษา:** ไทยแสดง "โด เร มี" คู่ตัวอักษรเป็นค่าตั้งต้นในโหมดเด็ก ผู้ใหญ่เลือกได้ (ต้องให้เจ้าของตัดสิน — หัวข้อ 6)
- **C3 เสียงและสั่นเบา ๆ เป็นรางวัลทันที:** ถูกโน้ตแล้วมีเสียงเล่นกลับอยู่แล้ว; เพิ่มสั่นเบา ๆ (`haptic`) ตอนถูกและเงียบตอนผิด (ไม่ใช้เสียงผิดแบบตำหนิ) — เสียงใหม่ต้องผ่านกฎ mic-safe ของ AGENTS.md
- **C4 ปุ่มใหญ่ขึ้นแบบมีเหตุผล:** เป้าสัมผัสขั้นต่ำ 48 px ในโหมดเด็ก (ทำแล้ว) และ 44 px ในโหมดผู้ใหญ่ (iOS/Android guideline)

### ระยะ D — สอนให้เก่งเร็วขึ้น (หลัง A–B ออกแล้วและวัดฐานได้)
- **D1 ความชำนาญรายโน้ตแบบมีความมั่นใจ:** เก็บต่อโน้ต (7 วันล่าสุด) จำนวนครั้งและอัตราถูก; โน้ตที่ < 4 ครั้งไม่นับเป็นจุดอ่อน (ตามกฎ `learner-signal`)
- **D2 ฝึกโน้ตที่อ่อนแทรกในรอบ:** รอบถัดไปเริ่มด้วย 3 โน้ตสั้นรอบโน้ตที่ติด (ใช้ `startSpotPractice` ที่มี) แทนการบังคับเล่นสเกลเต็มทุกครั้ง
- **D3 ปรับความยากเองด้วยหลักฐาน:** แม่น ≥ 90% สองรอบติด → เสนอปุ่มเดียว "ลองมืออีกข้าง/ช้าลง→เร็วขึ้น/คีย์ใหม่"; < 60% สองรอบติด → แบ่งท่อน — ไม่ขยับระดับจากข้อมูลน้อย
- **D4 สรุปรอบด้วยประโยคเดียว + ปุ่มเดียว** (มีแล้ว) เพิ่มดาวจังหวะแยก (P2-3 เดิม)
- **D5 วัดผลการช่วย:** บันทึกก่อน/หลังการช่วยของ level 2/3 ผ่าน `learning_intervene` (P2-5 เดิม) เพื่อรู้ว่าแบบไหนได้ผลจริง

## 4. สิ่งที่ต้องไม่ทำพัง
1. ห้ามเสียงใหม่ที่ไมค์จะได้ยินเป็นโน้ต (ต้องเป็น noise สูงกว่าเปียโนหรือ blacklist + มีเสียง mic-safe)
2. ห้ามเพิ่มเหรียญ/เจมจากการฝึก; รางวัลเป็น EXP/ดาว/ภาพ/เสียงเท่านั้น
3. `{th,en,zh}` ห้ามส่งเข้า JSX ตรง ๆ (ใช้ `tr()`); hook ทุกตัวเรียกทุกครั้ง (build ตรวจให้)
4. ตัวตัดสินใจ "ฝึกอะไรต่อ" มีตัวเดียว (`learnerSignal`)
5. **ห้ามใส่ backtick ในคอมเมนต์ CSS ที่อยู่ใน template string** — เกิดแล้วหนึ่งครั้งวันนี้ ทำให้แอปทั้งแอปล้ม และ `smoke-ux2` จับได้ (บทเรียน: build ผ่านไม่ได้แปลว่า CSS ถูกต้อง)
6. ทุกขั้นต้องผ่าน: `smoke-practice-mic-doubt` (17), `smoke-extract-notes` (11), `smoke-ux2` (16), `verify-chat` (ชุดปัจจุบัน), `verify-playalong` (50), `smoke-app-boot`

## 5. วัดอย่างไรว่า "ดีขึ้นจริง" (แทนคำว่าร้อยเท่า)
| ตัวชี้วัด | ฐานตอนนี้ | เป้า | วิธีวัด |
|---|---|---|---|
