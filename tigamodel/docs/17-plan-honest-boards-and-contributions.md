# 17 — แดชบอร์ดที่ไม่โกหก และคิวความรู้ที่ผู้ใหญ่ตัดสิน (m41 / m24 / m26 / m36 + ปุ่ม m35)

เขียน 2026-10-02 — รอบที่ต่อมาจาก docs/16: ปิดงาน `planned` ที่**ทำได้จริงโดยไม่ต้องปลอมข้อมูล**
(ทุกอย่างที่ต้องรอข้อมูลจริงหรือรอเจ้าของพลิกสวิตช์ ยังค้างอยู่และถูกระบุไว้ตรง ๆ ท้ายเอกสาร)

> หัวใจของรอบนี้: **สองแดชบอร์ดที่คุยกับคนนอก (พ่อแม่/ครู) และคิวที่คนนอกส่งความรู้เข้ามา
> ต้องเป็นสิ่งที่ "ไม่มีตัวเลข = ไม่มีคำตอบ" มากกว่าสิ่งที่ "ไม่มีตัวเลข = 0"**
> เพราะตัวเลขปลอมหนึ่งตัวทำลายความเชื่อถือทั้งบอร์ด — และคำสัญญาที่ทำจากข้อมูลแค่ 3 ครั้ง
> ก็คือคำโฆษณาในเครื่องแบบหนึ่ง

## ส่วนที่ 1: แดชบอร์ดวงจร A→B→C (m41, docs/12 §2)

`tigamodel/evaluation/compound-dashboard.js` (pure) + `scripts/compound-dashboard.mjs`
(read-only ผ่าน supabase CLI ช่องเดียวกับ m40/m43) — คำสั่งเดียวได้ทั้งสามวงจร

| กติกา | ทำอย่างไร |
|---|---|
| ไม่มีข้อมูล = `unavailable` | ไม่ใช่ 0 (ช่องที่วัดไม่ได้ขึ้น `ยังไม่มีข้อมูลจริง (ไม่ประมาณ)`) |
| เกณฑ์เปิดสวิตช์ = ตัวเลขของแผนเอง | A 20 คน (m08) · B 50 outcomes (m40) — ไม่มีตัวเลขใหม่ในโมดูลนี้ |
| เทรนด์ต้องมี 2 หน้าต่างจริง | outcomes สัปดาห์นี้ vs สัปดาห์ก่อน; มีหน้าต่างเดียว = ยังไม่มีเทรนด์ |
| % ตอบไม่ได้ ต้องมี baseline | ไม่มีค่าก่อน-wave = ไม่มีเปอร์เซ็นต์ (ค่าเดียวไม่ใช่ baseline) |
| วงจร A ต้องรอสวิตช์ | สวิตช์ปิด = ไม่พร้อม แม้จะมีข้อมูลครบ 20 คน (แผนยังไม่ผลิตจริง) |

ผลจริงรอบแรก (2026-10-02, live DB): **วัดได้ 6/7 ช่อง**
— A: 0 คนมี skill state (สวิตช์ `tiga_personalized_plans` ยังปิด) · B: 5 outcomes (ขาด 45) + 1 กลยุทธ์ ·
C: 0 diagnosis ที่ระบุทักษะ + ยังไม่มี baseline ของอัตรา ตอบไม่ได้ → **ไม่รายงาน %**

## ส่วนที่ 2: หลักฐานก่อน-หลังสำหรับพ่อแม่ (m24, docs/08)

`tigamodel/evaluation/before-after.js` (pure) — อ่าน `learning_practice_events` จริง

| กติกา | เหตุผล |
|---|---|
| เทียบรอบแรก ↔ รอบล่าสุด **ทักษะเดียวกัน** | คนละทักษะคือคนละเรื่อง ไม่ใช่ก่อน-หลัง |
| แถวที่ไม่มีคะแนน → เหลือแค่ "นาทีที่ซ้อม" | ไม่มีตัวเลขทั้งสองปลาย = ไม่มีตัวเลขเลย |
| 1 ครั้ง = ไม่ใช่เทรนด์ | ต้อง ≥3 ครั้งต่อคน และ ≥10 ครั้งทั้งกลุ่มก่อนขึ้น "เฉลี่ย" |
| ถดถอยรายงานตรงๆ | `declined` เป็นตัวเลขของจริงเหมือนกัน ไม่ถูกกลืน |
| ตารางว่าง = `insufficient` | ไม่ใช่ 0% |

**สถานะจริง: `learning_practice_events` = 0 แถว** → สคริปต์พิมพ์ว่า "ยังไม่มีแถวซ้อมจริงในตาราง —
เกิดเองเมื่อนักเรียนซ้อม ห้ามปลอม" (ผลจาก `scripts/compound-dashboard.mjs` จริง)
