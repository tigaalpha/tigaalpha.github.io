# 23 — แผน: ให้ BACKING TRACK "ตรงกับเพลง" (เจ้าของสั่ง 2026-10-03)

> เจ้าของ: *"ช่วยไปเพิ่มเสียงอื่นๆ ในแผนด้วย: เสียงสตริง, เสียงทุกอย่างที่เหมาะสมกับเพลง… ฉันต้องการให้ผู้เล่นเล่นแล้วสนุกและรู้สึกว่ามันเพราะด้วย ดังนั้น Backing Track จึงต้องเพราะ"*
> ต่อยอดจากเอกสาร 22 (แก้ "ไม่รู้ว่ามี") · เอกสารนี้แก้ **"มีแต่ไม่เหมาะกับเพลง"**
> กติกา: ทุกข้อผูกกับโค้ดที่อ่านจริง · ห้ามเสนอของที่มีอยู่แล้วว่าไม่มี · ห้ามแต่งตัวเลข

---

## 0. สรุปสั้น — ปัญหารากอยู่ที่ **ข้อมูล ไม่ใช่ที่เครื่องดนตรี**

`play-along-band.ts` มีเสียงพอใช้สร้างวงดนตรีได้เลย: กลอง 6 ชนิด · drone · bass · **strings** · brass · pluck · arpeggio (`play-along-band.ts:92–216`)

**แต่สิ่งที่วงดนตรีนี้ขาดคือ "เพลงนี้คือเพลงอะไร"** — `createBand()` รับแค่ `bars · beatsPerBar · pickup · spb · lead · endBeat · hand · level` (`:50`) และไม่มีพารามิเตอร์อื่นเลย

ผลคือ **เพลงบาร์อคกับเพลงดีบีสีได้วงเดียวกันเป๊ะ** ซึ่งไม่ใช่ "ไม่เพราะ" แต่คือ **"เพราะผิดเพลง"**

> **ข่าวดีที่ผมตรวจเจอ:** ข้อมูลแนวของเพลง **มีอยู่แล้วครบ 1,067 เพลง** ใน `SONG_GENRES` (`songs-data.ts:1416`) และถูกใช้อยู่แล้วในหน้าเลือกเพลง (`App.tsx:3954`) — ผู้เรียนเห็นแท็กยุคสมัยอยู่แล้ว แต่ **วงดนตร์ไม่เคยอ่านค่านี้เลย** งาน M2 จึงเป็นการเชื่อสายเดิม ไม่ใช่การสร้างข้อมูลใหม่

## 1. สิ่งที่ "ไม่ตรงกับเพลง" — วัดจากข้อมูลจริง

### 1.1 · **แนวเพลงมีอยู่แล้วครบทุกเพลง — แต่วงดนตร์ไม่เคยอ่านมัน**

วัดจาก `songs-data.ts:1416` (`SONG_GENRES`) ซึ่งรวม `CLASSICAL_ERAS` เข้าไปแล้วที่ `:1519`

| กลุ่ม | จำนวน |
|---|---|
| romantic | **542** |
| baroque | **235** |
| classical | **133** |
| impressionism | **54** |
| folk | 39 |
| cn | 23 |
| kids | 13 |
| carol | 7 |
| gospel | 7 |
| jazz | 6 |
| soul | 4 |
| neosoul | 4 |
| **รวม** | **1,067** | ครบทุกเพลง ไม่มีเพลงไหนว่าง |

> 192 เพลงสอน + 875 คลาสสิก = 1,067 ตรงกับที่ `AGENTS.md` เขียนไว้
> ตอนแรกผมนับได้ 1,066 เพราะเพลงหนึ่งมี id เป็นอักษรพิเศษ (`gymnopedié`) ทำให้ regex ที่ค้นหา id แบบ `[a-z0-9_]` มองข้าม — ตอนนี้นับด้วย 3 วิธีที่ตรงกัน

**แต่** `play-along-band.ts` ไม่ได้ import อะไรจาก `songs-data.ts` เลย — มันได้แค่ `bars / beatsPerBar / spb` ที่ `use-play-along.ts:848–849` ส่งมาให้
→ **ข้อมูลพร้อมแทบทั้งหมด แต่ไม่มีใครเอาไปใช้** นี่คือรากของ "ไม่เพราะ" แบบที่แก้ได้เลย

### 1.2 · จังหวะกลองไม่ตรงจังหวะเพลง — ข้อผิดพลาดที่ฟังออกทันที

รูปแบบกลองอยู่ที่ `play-along-band.ts:251–258`:
```js
if (p === 0 || (bpb === 4 && p === 2)) { kick(...) }   // kick ที่ 1 และ 3
else { snare(...) }                                    // snare ที่ 2 และ 4
hat(when, ...)                                         // hat ทุกครึ่งห้อง
```

จังหวะเพลงจริงในข้อมูล (`CLASSICAL_TIMESIG`):

| จังหวะ | จำนวน |
|---|---|
| 3/4 (วอลตซ์) | **375** |
| 2/4 | **123** |
| 4/4 (ค่าเริ่มต้นที่ `beatsPerBarOf` ตั้งไว้ — `play-along-progress.ts:70–73`) | 377 |

**เพลง 3/4 375 เพลง จะได้วง "kick สองครั้ง + snare หนึ่งครั้ง" ต่อห้อง** ซึ่งเป็นจังหวะร็อก 4/4 ที่ถูกยัดลงห้อง 3 ห้อง — นี่คือเหตุผลที่วอลตซ์ฟัง "เพี้ยน"

### 1.3 · `bpm` ไม่มีผลต่อวงดนตรีเลย

| ชุด | ช้าสุด | กลาง | เร็วสุด |
|---|---|---|---|
| เพลงสอน 191 | 52 | 96 | **180** |
| คลาสสิก 875 | 50 | 79 | **140** |

โค้ดไม่ได้อ่าน `bpm` เพื่อเลือกวง — เพลง 52 bpm (บาลาด) กับ 180 bpm (Soul Groove) ได้ชุดเดียวกัน

### 1.4 · เสียงสตริงมีอยู่ แต่เป็น "แผ่นรอง" ไม่ใช่สตริงจริง

`strings` เล่นที่ `:301` — `section(..., { type: "sawtooth", cutoff: 1350, detune: 7, partials: 3 })`
คือเสียงซ้อน 2 ตัวผ่านฟิลเตอร์เดียว ต่อ **คอร์ดทั้งก้อน** ไม่มีแนวเมโลดี้ ไม่มีการเคลื่อนที่ — เป็น "pad" มากกว่า "วงสตริง"

### 1.5 · เพลงสอน 192 เพลง — มีแนวครบทุกเพลง

`SONG_GENRES` ครอบเพลงสอนครบ **192/192** รวมกลุ่มที่ต้องใช้วงต่างกันจริง ๆ เช่น `jazz` 6 · `soul`+`neosoul` 8 · `gospel` 7 · `cn` 23

> ผมเดิมไล่จัดกลุ่มจาก **ชื่อเพลง** แล้วเจอ 149 เพลงที่จัดไม่ได้ — **นั่นเป็นความผิดพลาดของผมเอง** เพราะข้อมูลแนวมีอยู่แล้วในไฟล์ แผนนี้จึงใช้ข้อมูลนั้น ไม่ต้องเดาจากชื่อ

## 2. งาน 6 ข้อ เรียงตาม "ได้ยินผลเร็วที่สุด"

### ★ M1 · **จังหวะกลองตามจังหวะเพลง** — แก้ข้อผิดพลาดที่ฟังออกทันที

`play-along-band.ts:251–258` เปลี่ยนเป็นเลือกรูปแบบตาม `bpb`:

| `beatsPerBar` | รูปแบบที่ถูก |
|---|---|
| **3/4** | วอลตซ์: bass ที่ 1 · คอร์ด (ฮาร์ม/ออร์แกน) ที่ 2 และ 3 · **ไม่มี snare** |
| **2/4** | march: snare ที่ 1 และ 2 · bass สั้น |
| **4/4** | คงเดิม (rock/pop) |

**พิสูจน์:** `verify-playalong-band-audio.mjs` + สคริปต์ใหม่ที่ยืนยันว่าเพลง 3/4 **ไม่มีการเรียก snare**

> 375 เพลงได้ผลทันที · เสียงพร้อมใช้ (kick/bass/`section()`) ไม่ต้องเพิ่มอะไรใหม่เลย

---

### ★ M2 · **`STYLE` ต่อเพลง — ให้วงดนตรีรู้ว่าเพลงนี้เป็นแนวอะไร**

**ข้อมูลพร้อมอยู่แล้ว** — `SONG_GENRES` (`songs-data.ts:1416`) ครอบครบ 1,067 เพลง งานคือส่งค่านั้นเข้า `createBand()`:

```ts
// use-play-along.ts:848 — เพิ่มบรรทัดเดียว
createBand({ ..., style: SONG_GENRES[meta.id] })
```

ใน `play-along-band.ts` แปลงรหัสเป็นชุดเครื่องดนตรี:

```ts
// ตารางเดียวจบ ไม่ต้องแตะ songs-data.ts
const STYLE_KIT = {
  baroque:       { drums: "none",    lead: "harpsichord", pad: "continuo" },
  classical:     { drums: "timpani", lead: "strings",     pad: "strings"  },
  romantic:      { drums: "soft",    lead: "cello",       pad: "strings"  },
  impressionism: { drums: "none",    lead: "celesta",     pad: "softpad"  },
  kids:          { drums: "clap",    lead: "pluck",       pad: "musicbox" },
  folk:          { drums: "clap",    lead: "pluck",       pad: "pluck"    },
  cn:            { drums: "soft",    lead: "pluck",       pad: "pluck"    },
  carol:         { drums: "none",    lead: "bell",        pad: "organ"    },
  gospel:        { drums: "soft",    lead: "organ",       pad: "strings"  },
  jazz:          { drums: "ride",    lead: "pluck",       pad: "comping"  },
  soul:          { drums: "soft",    lead: "epiano",      pad: "strings"  },
  neosoul:       { drums: "soft",    lead: "epiano",      pad: "pad"      },
};
```

| ยุค/แนว | เพลง | วงที่จะได้ |
|---|---|---|
| **baroque** | 235 | คอนตินูโว — คีย์บาส์ + คอร์ดสูง + ฮาร์ปซิคอร์ด · **ไม่มีกลอง** |
| **classical** | 133 | สตริง + คีย์บาส์ + ทิมปานีเบา |
| **romantic** | 542 | สตริงเต็ม + มีดึกซู่ · ซีลโล |
| **impressionism** | 53 | เซลสตา/กล๊อก + ปาดซอฟต์ + สตริงเบา · ไม่มีเครื่องกระทบ |
| **folk** | 39 | กีตาร์/อูดูเลอี + คอร์ดกระจกประ |
| **cn** | 23 | เครื่องแบบจีน — พล็อก/ปี่ บวกกลองตามจังหวะเพลง |
| **kids** | 13 | กล๊อกสองเสียง + คอร์ดกระจกประ (ครูกับเด็ก) |
| **gospel** | 7 | ออร์แกน + สตริงอบอุ่น |
| **soul / neosoul** | 8 | คีย์บาส์อิเล็กทรอนิกส์ + เบสซิงเกิล |
| **jazz** | 6 | ไรด์ไซม์ + เบสเดิน + คอร์ดที่ 7/9 |
| **carol** | 7 | ออร์แกน + เบลล์ (ครุณครี) |
| **ไม่รู้แนว** | **0** | ไม่มีเพลงไหนตกหล่น — ครบ 1,067 (เผื่อเพลงที่ผู้ใช้สร้างเอง → ใช้วงเดิม) |

**กติกาที่ห้ามละเมิด:**
1. **`SONG_GENRES[meta.id]` ที่ไม่รู้จัก → ใช้วงเดิมเป๊ะ** (เผื่อเพลงที่ผู้ใช้สร้างเอง หรือแนวใหม่ที่ยังไม่มีในตาราง) — ห้ามเดา
2. **ห้ามเพิ่มเสียงใหม่เกิน 6 รายการต่อแนว** ทุกตัวต้องสร้างจาก `section()` / `pluck()` / `bass()` / `noiseHit()` ที่มีอยู่
3. **เสียงพิตช์ใหม่ทุกตัวต้องเรียก `suppress()`** ตาม `verify-playalong-mic-band.mjs`
4. **`Style` ห้ามมีผลกับคะแนน/จังหวะที่วัด** — เป็นเสียงอย่างเดียว (บันทึกลง `log[i].style` เพื่อพิสูจน์ได้)

**พิสูจน์:** สคริปต์ใหม่ — เพลง 1 เพลงจากแต่ละแนว (12 แนว) → ตรวจว่า `log` มีแต่กลองของแนวนั้น · และเพลงที่ไม่รู้แนวต้องได้วงเดิมทุกตัว

### ★ M3 · **เพิ่มเสียงใหม่ 4 ตัว** (ทั้งหมดสร้างจากของที่มีอยู่)

| เสียง | สร้างจาก | ใช้กับแนว |
|---|---|---|
| **ฮาร์ปซิคอร์ด** | `pluck()` + ฟิลเตอร์เปิดกว้าง | baroque 235 |
| **ออร์แกน** | `section({ type: "square", partials: 5, detune: 4 })` | baroque · carol 7 |
| **เซลสตา/กล๊อก** | `section({ type: "sine", partials: 3 })` สูง ๆ + `echo` | impressionism 53 |
| **เบสซิงเกิล (soul)** | `bass()` ที่ `hand === "left"` ก็เล่นได้ · ตัดสร้างใหม่ | soul + neosoul 8 |
| **เบลล์** | ต่อยอดจาก `playChordDing()` (`:369`) ที่มีอยู่แล้ว | carol 7 · finale |

> **เสียงสตริงไม่ต้องสร้างใหม่ — มีอยู่แล้วและดีพอ** ที่ `:301` · งานจริงคือ M2 บอกว่าเพลงไหนควรได้สตริง (ตอนนี้ได้สตริงเฉพาะ combo ≥ 8 เท่านั้น จะได้ตั้งแต่แรกถ้าเป็นเพลงสตริงจริง)

### ★ M4 · **จังหวะคลุ่มเสียงสัมผัสกับ tempo**

`bpm` มีอยู่แล้วทุกเพลง (52–180) แต่ไม่มีผล — ใช้เป็น**ตัวหารอัตโนมัติแบบเดียว** (กดปุ่มเดียวให้เล่นได้ ไม่ต้องคิด):

| ช่วง bpm | ผลกับวง |
|---|---|
| **< 70** (บาลาด/นอกเทน) ตัด hat ทุกครึ่งห้องออก · ลด kick |
| **70–120** | รูปแบบปกติ |
| **> 140** (Soul/ป๊อปเร็ว) · เพิ่ม hat 16th ตั้งแต่ Fever · bass สั้นลง |

**ไม่ใช่การสุ่ม** — คำนวณจาก bpm ของเพลงล้วน ๆ ผู้เล่นเล่นซ้ำเพลงเดิมต้องได้ผลเหมือนเดิมทุกครั้ง

---

### ★ M5 · **สตริง "มีแนว" — ไม่ใช่แผ่นรอง** (เสริมความเพราะ)

`strings` ปัจจุบันเล่นคอร์ดทั้งก้อนพร้อมกัน (`:301`) — เพิ่ม **แนวเมโลดี้สูงกว่าคอร์ด 1–2 โน้ต** เล่นตามจังหวะของเพลง โดยยึดโน้ตใน `bars[].pcs`

> ทำให้สตริงฟังเป็น "วง" ไม่ใช่ "เสียงพื้นหลัง" · เสียงยังอยู่เหนือเปียโนเหมือนเดิม (ที่ `oct` เดิม + ไม่ลดลง)

---

### ★ M6 · **เปิด "เต็ม" เฉพาะบางเพลง** (ต่อยอด B2 ของเอกสาร 22)

`BAND_LEVELS = [0, 0.55, 1]` (`:36`) ปัจจุบันสูงสุดคือ 1.0 — เพลงที่ควรได้เต็มจริง (jazz/soul/baroque) เพิ่มระดับ **1.35** ในโหมด "เต็ม" ของ B2

**ข้อแม้ที่ห้ามลืม:** เพิ่มระดับ = ดังขึ้น → **ต้องรัน `verify-playalong-mic-band.mjs`** ว่าสตริง/ฮาร์ปซิคอร์ดที่เพิ่มไม่ทำให้ตัวตรวจจับโน้ตเพี้ยน

## 7. หมายเหตุความถูกต้อง — ผมแก้ความผิดพลาดของตัวเอง 2 จุด

**ผิดข้อ 1 — "149 เพลงไม่มีแนว"**
ตอนแรกผมไล่จัดกลุ่มเพลงจาก **ชื่อเพลง** แล้วสรุปว่าต้องหาแนวเพิ่ม
→ ผิด · `SONG_GENRES` กำกับครบทุกเพลงอยู่แล้ว และ `:1519` รวม `CLASSICAL_ERAS` เข้าไปอีก 875
→ ถ้าใช้แผนเดิม จะเผลาว่าไปเพิ่มข้อมูลซ้ำซ้อนทั้งที่ของเดิมมีอยู่แล้ว

**ผิดข้อ 2 — "เพลงสอนมีแนว 191 เพลง"**
ผมใช้ regex `[a-z0-9_]` นับ id ของเพลง ได้ 191 แต่จริงคือ **192** เพราะเพลงหนึ่งมี id เป็นอักษรพิเศษ: `gymnopedié` (ซาตี)
→ และเพลงนั้น**มีแนวอยู่แล้ว** (`gymnopedié: "impressionism"` ที่ `songs-data.ts:1490`) — ผมตอนแรกไปสรุปว่าขาดแนว ซึ่งผิดอีกชั้น เพราะ regex ตัวที่สองก็มองข้าม id ตัวเดียวกัน

> ผิดสองรอบจากการเชื่อ regex ตัวเดียว ตอนนี้ `scripts/smoke-band-style.mjs` ตรวจเรื่องนี้ทุกครั้งที่รัน และนับด้วย 3 วิธีที่ตรงกัน

## บั๊กที่เจอระหว่างทำ — แก้จากสาเหตุ

1. **log โกหกว่ามี hat ทั้งที่ไม่ได้เล่น** — `entry.drum` ตั้งค่าเริ่มเป็น `"hat"` แต่หลัง M1 ห้อง 2/4 กับ 3/4 ไม่ได้เล่น hat บนครึ่งห้องแล้ว → เปลี่ยนเป็นตั้งค่าเฉพาะตอนที่สั่งเล่นจริง (ค่าว่าง = ไม่ได้เล่นอะไร)
2. **ตัวช่วยในสคริปต์สร้างคอร์ดยาวห้องตายตัว 4 บีต** — ทำให้ฉาก 2/4 และ 3/4 ที่ผมทดสอบไม่มีห้องสุดท้าย ฟันดูเหมือนวงดนตร์เล่น finale ไม่ได้ ทั้งที่โค้ดจริงถูก → แก้ที่ตัวช่วย
3. **เกณฑ์ "สแนร์ควรอยู่ตรงไหน" ที่ผมเขียนในสคริปต์ไม่ครบ 2 รอบ** — ครั้งแรกลืมชุด `soft` ครั้งที่สองลืมว่า "จังหวะชนะชุดกลอง" · ทั้งสองครั้ง **โค้ดจริงถูกอยู่แล้ว** ผิดที่ตัวช่วย
4. **fake AudioContext ที่ผมเขียนในสคริปต์ทำให้วงดนตร์หยุดครึ่งห้อง** — `currentTime` ไม่เดิน วงเล่นจองได้แค่ 0.35 วินาทีแรก → แก้ที่สตับ ไม่แตะโค้ดจริง (ถ้าไม่จับได้จุดนี้จะเขียนว่า "3/4 ผ่าน" ทั้งที่วัดแค่ 2 บีต)
