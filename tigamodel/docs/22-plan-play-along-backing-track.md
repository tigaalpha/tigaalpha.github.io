# 22 — แผน: BACKING TRACK ของ PLAY ALONG ให้ดีขึ้น (เจ้าของสั่ง 2026-10-03)

> เจ้าของ: *"ย้ายกลับไปที่ฟีเจอร์ Play Along ฉันต้องการให้ backing track มัน มีเสียงประกอบตอนเล่นเกม"*
> กติกาของเอกสารนี้: ทุกข้อต้องผูกกับโค้ดที่อ่านจริง · **ห้ามเสนอสิ่งที่มีอยู่แล้วว่าไม่มี** · ห้ามแต่งตัวเลข

---

## 0. ข้อค้นพบสำคัญที่สุด — backing track **มีอยู่แล้วและครบมาก**

ผมไล่โค้ดก่อนเขียนแผน แล้วพบว่า `play-along-band.ts` (383 บรรทัด) ทำงานนี้ไว้แล้ว:

| สิ่งที่มี | หลักฐานในโค้ด |
|---|---|
| **วงดนตรีสังเคราะห์** ไม่มีไฟล์เสียงเลย | `ls public/*.mp3 public/*.ogg` = ว่าง · ทุกเสียงสร้างด้วย oscillator |
| กลองอย่างเดียวตลอดเพลง | kick · snare + clap · closed/open hat · tom fill ทุก 4 ห้อง · crash |
| drone อุ่น ๆ ใต้ทุกอย่าง | `drone` |
| ดนตรี **สะสมขึ้นตามผู้เล่น** | bass เมื่อ combo ≥ 3 · strings + open hat เมื่อ ≥ 8 · Fever เพิ่ม brass · arpeggio · hat 16th |
| พลาด → ดนตรีถอยกลับไปเหลือกลอง แต่**กลองไม่หยุด** | ไม่ให้เสียจังหวะ |
| ปุ่มเลือก 3 ระดับ + โหมด | `AccompMode` (`SongPlayOverlay.tsx:276`) + ปุ่ม 🔉 ปิด/เบา/ปกติ (`:331`) |
| ตั้งค่าแล้วจำข้าม session | `tg_pa_band` · `tg_pa_accomp` (`use-play-along.ts:532,502`) |
| **ปุ่มอยู่ในหน้าเล่นด้วย** | `SongPlayOverlay.tsx:454` (`variant="hdr"`) ไม่ใช่แค่ในหน้าพัก |
| mic-safe | ตอนเปิดไมค์ → กลองอย่างเดียว (ไม่มี pitch ให้ตัวตรวจจับโน้ต) · เมื่อแตะจอ → เต็มพร้อม blacklist (`_accMarkSuppress`) |

**ดังนั้นคำถามจริงไม่ใช่ "จะเพิ่ม backing track ยังไง" แต่คือ "ทำไมผู้เรียนรู้สึกว่าไม่มี"** — แผนนี้จึงแก้ที่การ *ได้ยิน* และ *สัมผัส* ไม่ใช่สร้างของใหม่

## 1. ข้อจำกัดที่ทำให้มัน "ไม่มีเสียงประกอบ" — อ่านจากโค้ด

| # | ข้อจำกัด | บรรทัด | ผลกับผู้เรียน |
|---|---|---|---|
| **1** | **`pump()` ทำงานบน audio clock และหยุดทันทีที่ `_sfxMuted`** | `play-along-band.ts:220` | กดปิดเสียงทั้งแอป → วงดนตรีหายตาม ๆ ทั้งที่ควรได้ยิน |
| **2** | **มีแต่ 3 ระดับ: ปิด / เบา / ปกติ** | `BAND_LEVELS = [0, 0.55, 1]` (`:36`) | ไม่มี "เต็ม" — ผู้เล่นจริงจังอยากได้เสียงเต็มกว่านี้ไม่ได้ |
| **3** | **โหมดมีแค่ 2: วงดนตรี หรือ เมโทรโนม** | `songAccomp`: `v === "metro" ? "metro" : "track"` (`use-play-along.ts:511`) | ถ้าคนหนึ่งเคยเลือกเมโทรโนม เขา**ไม่มีทางได้ทั้งสองอย่าง** |
| **4** | **เมื่อเปิดไมค์ → เหลือกลองอย่างเดียว** | ไฟล์เปิดอธิบายเอง | คนเล่นเปียโนจริง **ได้ยินแค่กลอง** — น่าจะรู้สึกว่า "ไม่มีประกอบ" มากที่สุด |
| **5** | **โหมดมือซ้าย/สองมือ → วงดนตรีเล่นเบสไม่ได้** | ไฟล์เปิดอธิบายเอง | ถูกต้องเชิงดนตรี แต่ทำให้เหลือแค่กลอง+คอร์ด = เบามาก |
| **6** | **ค่าเริ่มต้นเดาจาก localStorage เก่า** | `:506` `tg_pa_band === 0 && tg_pa_metro !== 0 ? "metro" : "track"` | คนที่เคยปิดวงดนตรีทิ้งไว้ → **ตลอดไปได้เมโทรโนม** |
| **7** | ปุ่มอยู่มุมหัวข้อจอ | `SongPlayOverlay.tsx:454` | เล็กจนมองไม่เห็นตอนเล่น |

## 2. 5 การแก้ เรียงตาม "ผู้เรียนได้ยินได้เร็วที่สุด"

### ★ B1 · **เมโทรโนม + วงดนตรี พร้อมกันได้** — แก้ #3
> *ตอนนี้เลือกได้อย่างใดอย่างหนึ่ง ซึ่งทำให้คนที่อยากได้ทั้งสองอย่างเลือกผิดข้าง*

เพิ่มโหมดที่สาม `"both"` — เมโทรโนมคลิกกับวงดนตรีพร้อมกัน (เสียงคลิกจะเบาลงให้อยู่ใต้วงดนตรี ไม่แย่งกัน)
**พิสูจน์:** ปุ่ม 3 ระดับสลับได้ครบ · เมโทรโนมยังชัวร์จังหวะไว้เหมือนเดิม

### ★ B2 · **เพิ่มระดับเสียงใหม่: "เต็ม"** — แก้ #2
> *ระดับสูงสุดปัจจุบันคือ 1.0 ซึ่งคือ "ปกติ" — ไม่ใช่เต็ม*

`BAND_LEVELS` เป็น `[0, 0.55, 1]` เพิ่มเป็น **`[0, 0.55, 1, 1.35]`** พร้อมป้าย "เต็ม"
**พิสูจน์:** ระดับใหม่ไม่กลัว clip → วัด peak จริงหลังทำ

### ★ B3 · **เปิดไมค์แล้วยังได้ยินคอร์ด** — แก้ #4 (ข้อที่น่าจะกระทบมากที่สุด)
> *ตอนนี้เปิดไมค์ = ได้แค่กลอง เพราะเสียงวงดนตรีมี pitch และตัวตรวจจับโน้ตจะจับได้*

ทางแก้ที่ถูกต้องตามหลักเสียง: ในโหมดไมค์ ให้ **คอร์ดประสานเสียงไม่มี** แต่ยังมี drone + กลอง + ซีด (seating pad)
คือเปลี่ยนจาก "ไม่มีอะไรนอกจากกลอง" เป็น "ยังมีเสียงต่อเนื่อง แต่ไม่มีโน้ตที่ตัวตรวจจับจะจับผิด"
**พิสูจน์:** `verify-playalong-mic-band.mjs` ต้องยังผ่าน · วัดว่าไมค์เทียบกับการเล่นเพลงจริง

### ★ B4 · **ค่าเริ่มต้นใหม่สำหรับคนที่เคยปิดวงดนตรีไว้** — แก้ #6
> *คนที่เคยกด "ปิด" ครั้งเดียว จะได้เมโทรโนมไปตลอดชีวิต*

กติกาเดิมคงไว้ (ไม่แย่งสิทธิ์ผู้ใช้) แต่เพิ่ม: ถ้าเลือก `track` และปิดวงดนตรี **เกิน 14 วัน** ให้ถามครั้งเดียวว่าจะเปิดไหม
**หรือ** เฉย ๆ: ใส่ทางลัด "วงดนตรี" ในหน้าพักให้เห็นชัด (มีอยู่แล้วแต่จมอยู่ใต้ปุ่มอื่น)
**พิสูจน์:** ไม่มีการเขียนทับค่าที่ผู้ใช้ตั้งเอง

### ★ B5 · **ทำให้เห็นว่ามีเสียงประกอบ** — แก้ #7
> *ของอยู่แล้วแต่คนไม่รู้ว่ามี*

- แถบหัวข้อจอ: เมื่อกดเล่น แสดงชื่อสิ่งที่กำลังเล่น (`🎼 วงดนตรี · 5 เสียง`) เป็นตัวเล็ก ๆ 1 วินาที แล้วจาง
- ครั้งแรกที่เล่น: ข้อความสั้น ๆ ว่ามีปุ่มนี้อยู่ตรงนี้ (ครั้งเดียว แล้วจำ)
**พิสูจน์:** ไม่มี popup บังเกม · ไม่ผิดกติกาเดิมที่เคยห้าม popup

## 3. สิ่งที่ผมจะไม่ทำ และเหตุผล

| ไม่ทำ | เหตุผล |
|---|---|
| ดาวน์โหลดไฟล์เสียงจริง | ทุกเสียงสังเคราะห์ 0 ไบต์ · ไม่ต้องรอโหลด · ผู้เล่นออฟไลน์ได้ · เปลี่ยนคีย์/เทมโปได้ทันที |
| เพิ่ม bass ในโหมดมือซ้าย | แย่งมือผู้เล่น · กติกาดนตรี ไม่ใช่ข้อจำกัดเทคนิค |
| เพิ่มเสียงพิตช์ในโหมดไมค์ | ตัวตรวจจับโน้ตจะจับเพลงวงดนตรีเป็นโน้ตของผู้เล่น → คะแนนเพี้ยน · `AGENTS.md` เขียนไว้ชัด |
| เอาเมโทรโนมออก | ผู้เริ่มต้นต้องมี · ตอนนี้ต้องเลือกข้าง แต่ B1 จะได้ทั้งคู่ |
| แตะ `speech.ts` / TTS | ถูกปิดด้วย kill switch ตามคำสั่งเจ้าของ |
| เพิ่มผู้เล่นออนไลน์เล่นด้วยกัน | นอกขอบเขต · ไม่เกี่ยวคำขอ |

## 5. สิ่งที่ยังพิสูจน์ไม่ได้ (สำคัญ — อ่านก่อนสั่งงาน)

| # | ยังไม่รู้ | ต้องการ |
|---|---|---|
| 1 | **ผู้เรียนรู้สึกว่าไม่มีเสียงประกอบจริงไหม** | เล่นจริงแล้วฟัง · ผมวัดได้แค่โค้ด |
| 2 | **เสียงดังขนาดไหนจึงดีพอ** | วัดระดับที่กลองกับวงดนตรีไม่กลบกัน |
| 3 | **เปิดไมค์แล้วคอร์ดทำให้ตัวตรวจจับโน้ตเพี้ยนไหม** | **ต้องมีเสียงจริง** — คอนเทนเนอร์นี้วัดไม่ได้ |
| 4 | วงดนตรีทำให้ผู้เรียนเล่นเก่งขึ้นจริงไหม | ต้องมีข้อมูลการเล่นจริง |

**ข้อ 1 สำคัญที่สุด:** อาจจริงแล้วปัญหาไม่ใช่ "เสียงไม่ดี" แต่คือ **"ไม่รู้ว่ามี" หรือ "เปิดไมค์แล้วเหลือแค่กลอง"**
ถ้าขอแก้ตาม B3–B5 ก่อน ก็น่าจะตรงกว่าการเพิ่มเสียงใหม่
