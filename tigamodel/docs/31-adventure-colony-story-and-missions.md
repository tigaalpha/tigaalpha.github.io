# 31 · Adventure: เรื่องราวอาณานิคมและประเภทภารกิจ (เจ้าของ 2026-10-11)

ต่อจาก `29-adventure-story-canon.md` และ `30-plan-adventure-fun.md`

## เนื้อเรื่อง
ปี 2100 มนุษย์สร้าง **หุ่นยนต์ผู้บุกเบิก** (ตัวที่ผู้เล่นควบคุม) เพื่อทำงานสร้างอาณานิคมแทนมนุษย์ ก่อนที่คนจะย้ายเข้าอยู่:
เคลียร์เอเลี่ยน, ขุดแร่และทรัพยากรส่งกลับโลก, ยึดดาวฤกษ์และดาวแก๊สของระบบดาวอื่น, และกำจัดกองกำลังต่างดาว

## ภารกิจที่ทำแล้ว (ใน `adventure.tsx`)
| ประเภท | แผนที่ | วิธีเล่น |
|---|---|---|
| บุกเบิก/ล่าบอส | Luma, Ferro, Kryo, Pyra, Nexa | วิ่งสู้ถึงลานบอส |
| เก็บพลังงาน (เอาตัวรอด) | Jovia (ดาวแก๊ส) | ยืนหยัด 90 วิ ขณะพลังงานเต็ม |
| ขุดแร่ส่งโลก | Cobalt Belt | ทุบก้อนแร่ ≥10 ก้อน ส่งแคปซูลที่แท่นขวาสุด → นับเข้า "ส่งกลับโลก" (`tg_earth_ore`) อาณานิคมโตเป็น ฐาน/ค่าย/เมือง/มหานคร |
| ยึดดาวฤกษ์ | Helios | ยืนยึดสถานีเก็บพลังงาน 3 จุด จุดละ 10 วิ ขณะมีคลื่นศัตรู |
| ทิ้งนิวเคลียร์แล้วบุก | Ashfall | ด่านวงโคจร: ปล่อยหัวรบ 3 ลูกใส่ฐาน 6 แห่ง ฐานที่โดนไม่มีทหารตอนบุกพื้นดิน แล้วสู้บอสผู้บัญชาการ |
อาวุธ: ปืน/เลเซอร์ 4 แบบ (พัลส์, กระจาย, ทะลวง, อาร์ค) และจรวด 3 แบบ (นำวิถี, คลัสเตอร์, นาปาล์ม) ปลดล็อกตามดาวที่ผ่าน

## ยังไม่ได้ทำ (เรียงตามที่แนะนำ)
1. **ขับยานอวกาศไล่ยิงเอเลี่ยน** — เป็นโหมดเกมใหม่ (มุมมองยานเลื่อนแนวนอน/แนวตั้ง, ยานคือ "หุ่นยนต์ขับยาน", ศัตรูเป็นฝูง) ต้องมีเอนจินของตัวเอง ประมาณงานเท่า Adventure รอบแรก
2. **ยึดดาวแก๊ส "ของจักรวาลอื่น"** — ต่อยอด Jovia/Helios เป็นด่านที่มี 2 เฟส (บนยาน → ลงเก็บพลังงาน) และมอนสเตอร์ชุดใหม่
3. **ภูมิประเทศเฉพาะดาว** — ตอนนี้ฉากเป็นรูปป่าเรืองแสงเปลี่ยนสีเท่านั้น
4. **แร่หลายชนิด/รถขุด/ยานขนส่ง** — ให้ระบบ "ส่งกลับโลก" มีความหมายยิ่งขึ้น (ปลดสกินอาณานิคม ฯลฯ ยังไม่ผูกกับรางวัลใดเลย ห้ามผูกกับการขายของ)
5. **ออนไลน์ร่วมกัน** — ต้องออกแบบตาราง + SQL ให้เจ้าของอนุมัติ
