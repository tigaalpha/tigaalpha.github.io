# 32 · แผน: ออกจากโลก → ขับยานเก็บทรัพยากร → ยึดดาวฤกษ์ (Adventure ภาค "การเดินทางในอวกาศ")

ที่มา: ไอเดียของเจ้าของ 2026-10-11 — ด่านเดินทางออกจากโลกพร้อมหนังปลุกใจ, ส่งยนต์/หุ่นยนต์ไปยึดดาวฤกษ์, ด่านขับยานอวกาศไล่ยิงและเก็บดาวเคราะห์น้อยเพื่อขุดแร่, เก็บทรัพยากรจากดาวแก๊ส, ไม่ต้องเป็นเกมตีมอนสเตอร์เก็บเลเวลอย่างเดียว และ **เควสต์ทุกอย่างยังตอบคำถามดนตรีเหมือนเดิม** นี่คือร่างแผน รอเจ้าของมาเสริมก่อนลงมือ

## 0. สิ่งที่มีอยู่แล้ว (ต่อยอดได้เลย)
- โหมดขับยานไล่ยิง `adventure-ship.tsx` ด่าน **Void Gate** (คลื่นศัตรู → เรือแม่, เก็บคริสตัล/ของดรอป, ขายเป็นเหรียญตามเพดานรายวัน)
- ภารกิจขุดแร่บนดาว Cobalt (ส่งแคปซูลกลับโลก นับเป็นระดับอาณานิคม), ยึดสถานีเก็บพลังงาน Helios, เก็บพลังงาน Jovia
- หนังก่อนแมปที่วาดด้วยโค้ด (`adventure-cine.tsx`): โลก 2100 → โรงงาน → ปล่อยฝูงยาน → ถึงดาว → ภารกิจ
- ระบบคำถามดนตรี: จุดคำถาม (beacon) 1 คำถามต่อครั้ง, เวทย์คอร์ด (`quiz-quest.ts`)
- คริสตัล/เหรียญ: ได้จากการเล่นเท่านั้น ห้ามขาย (กฎเดิม)

## 1. โครงเรื่อง "ภาคอวกาศ" (Act 2)
ปี 2100 หลังโลกตั้งฐานบนดาวใกล้เคียง มนุษย์ส่ง **กองเรือบุกเบิก** ออกไปไกลกว่าระบบสุริยะ: เก็บแร่จากสายพานดาวเคราะห์น้อย ดูดพลังงานจากดาวแก๊ส และ "ผูกสถานีเก็บพลังงาน" รอบดาวฤกษ์ต่างระบบเพื่อส่งพลังงานกลับโลก ระหว่างทางเจอฝูงเอเลี่ยนที่หวงทรัพยากรเหมือนกัน

## 2. ด่านใหม่ที่เสนอ (เรียงตามลำดับเล่น)
| # | ด่าน | รูปแบบเกม | ได้อะไร |
|---|------|-----------|---------|
| A | **Departure · ออกจากโลก** | หนังปลุกใจเต็มเรื่อง (ไม่มีการเล่น) + เกมสั้น "ฝ่าชั้นบรรยากาศ" แตะหลบเศษขยะอวกาศ 30 วินาที | ปลดล็อกยาน, เปิดแผนที่อวกาศ |
| B | **Asteroid Belt · ขับยานขุดแร่** | ขับยานเลื่อนแนวนอน ยิงหินให้แตกเป็นแร่ (เหล็ก/ทอง/คริสตัล/แกนพลังงาน) เก็บด้วยลำแสงดูด, มีโจรอวกาศแทรก, เต็มช่องบรรทุกแล้วส่งแคปซูลกลับโลก | แร่ → ขายเป็นเหรียญ (เพดานรายวันเดิม) + นับเป็นระดับอาณานิคม |
| C | **Gas Giant Skim · ดูดพลังงานดาวแก๊ส** | ยานบินเฉียดชั้นเมฆ: อยู่ในชั้นพลังงาน (ช่องแคบๆ) นานพอเพื่อเติมถัง, เลี่ยงพายุฟ้าผ่า, ปล่อยโดรนดูดแก๊สเป็นช่วงๆ | แก๊สพลังงาน → แปลงเป็นคริสตัล |
| D | **Star Harvest · ยึดดาวฤกษ์** | วางสถานีเก็บพลังงาน 3 จุดรอบดาว (ขับยานไปจอดและป้องกันคลื่นศัตรู) แล้วเปิดสวิตช์พร้อมกัน, ช่วงท้าย "พายุสุริยะ" ต้องหลบ | EXP + ระดับอาณานิคม + สกินยาน |
| E | **Void Gate (มีแล้ว)** | ศึกอากาศ + เรือแม่ | ปรับให้เป็นบทสุดท้ายของภาคนี้ |

หนังนำเรื่องแต่ละด่านใช้ระบบหนังเดิม (ตอนนี้ยาวขึ้น + ซับกลางจอ + สไตล์ Dune/Star Wars) เพิ่ม scene ใหม่: ยานทะยานออกจากฐานปล่อยจรวด, ชมโลกเล็กลงเรื่อยๆ, ผ่านวงแหวนดาวเคราะห์

## 3. หนัง "ส่งออกจากโลก" (ด่าน A) — ร่างบท
1. ผู้คนบนจัตุรัส/ศูนย์ควบคุมมองขึ้นฟ้า (คำบรรยายกลางจอ)
2. นับถอยหลัง 10…1 พร้อมเสียงกลองทิมปานีไต่ระดับ
3. แท่นยิงปล่อยยานขนส่งหุ่นยนต์ขึ้นสู่ท้องฟ้า (ไฟพุ่ง, เมฆแตกวง)
4. โลกกลมเล็กลงเรื่อยๆ พร้อมประโยคปลุกใจ ("นี่ไม่ใช่การจากลา — แต่คือการเริ่มต้นของมนุษยชาติ")
5. กองเรือหลายลำจัดขบวน, ธีมทองเหลืองเต็มวง, ตัดเข้า objective card
- ภาพ/เพลงใช้ epicLook + `scheduleCineScore` ที่มีอยู่, เพิ่มฉาก `liftoff` และ `earthfade`
- หนังเต็มจอแนวนอนเหมือนที่ทำไว้ (ล็อกแนวนอน/หมุนเอง)

## 4. กลไกใหม่ที่ต้องทำ (ใช้เอนจินยานเดิมต่อยอด)
1. **เอนจินยานแบบ "โหมด"**: แยก `adventure-ship.tsx` เป็นแกนกลาง + โหมด (`dogfight`, `mine`, `skim`, `harvest`) ใช้ร่วม: ควบคุม, HUD, ลูกกระสุน, ของดรอป, การเก็บ, ผลสรุป
2. **ขุดแร่ในสายพาน (mine)**: หินหลายขนาดแตกเป็นชิ้น, ชนิดแร่สุ่มตามระดับด่าน, ลำแสงดูด (กดค้าง), ช่องบรรทุก (cap) — ต้องตัดสินใจส่งกลับโลกหรือไปต่อ
3. **ถังพลังงาน/โซนเมฆ (skim)**: แถบ "ชั้นพลังงาน" เลื่อนขึ้นลง ต้องบินตามอยู่ในแถบ
4. **สถานีดาวฤกษ์ (harvest)**: จุดจอด 3 จุด, ยึดแบบนับเวลา (เหมือน Helios) แต่เป็นยาน
5. **ปรับยาน**: เพิ่มช่องอัปเกรด "ยาน" (เกราะ, ความเร็ว, ความจุบรรทุก, ระยะดูด) ใช้คริสตัลเหมือนช่องเดิม — *ห้ามซื้อด้วยเงินจริง*
6. **แผนที่อวกาศ**: เมนูเลือกดาวเปลี่ยนเป็นแผนที่ดาวกลุ่ม (ภาค 1 บนพื้นผิว / ภาค 2 อวกาศ) แทนรายการยาว

## 5. เควสต์ดนตรีในภาคอวกาศ (ไม่ทิ้งแก่นของแอป)
- **สถานีเก็บแร่/พลังงานทุกจุด = beacon คำถาม 1 ข้อ**: ตอบถูกได้โบนัส (ลำแสงดูดกว้างขึ้น/แร่คูณ 1.5 ชั่วคราว), ตอบผิดโชว์บทเรียนบนเปียโนแล้วไปต่อ
- **เวทย์คอร์ดบนยาน**: เกจพลังเต็ม → ถามคอร์ด/อินเทอร์วัล → ตอบถูก = ระเบิดเลเซอร์ล้างจอ (ใช้ `nextSpell` เดิม)
- **ปลดล็อกประตูด่านด้วยโน้ต**: "ประตูวาร์ป" ต้องกดลำดับโน้ตให้ตรงทำนองสั้น (ใช้โน้ตที่ผู้เล่นเรียนมาแล้ว)
- กติกาเดิมคงไว้: 1 คำถามต่อครั้ง, ใช้เปียโนบนจอ ไม่ใช้ไมค์, ไม่มีการจ่ายเหรียญเพราะตอบถูก (จ่าย EXP เท่านั้น)

## 6. เศรษฐกิจ (กฎเหล็กเดิม)
- แร่/พลังงาน → ขายเป็นเหรียญได้ตามกติกา Adventure เดิม: เต็มราคาเมื่อจบด่าน, 40% เมื่อออกกลางคัน, **เพดาน 800 เหรียญ/วัน** ปรับได้ที่เดียว (`ADV_COIN_DAY_CAP`)
- คริสตัล = จากการเล่นเท่านั้น ใช้อัปเกรดยาน/หุ่น **ห้ามขาย**
- ไม่มีตัวคูณตามแพ็กเกจ และไม่มีทางซื้อเหรียญด้วยเงินจริง

## 7. ลำดับงาน (เสนอ 5 เฟส)
1. **S1 หนังออกจากโลก + ด่าน A** (หนังใหม่ + เกมสั้น) — ปลดล็อกภาค 2
2. **S2 รีแฟกเตอร์เอนจินยานเป็นโหมด + อัปเกรดยาน** (ไม่มีเนื้อหาใหม่ แต่ทำให้ B–D ถูกลง)
3. **S3 ด่าน B ขุดแร่สายพาน** + ระบบบรรทุก/ส่งกลับโลก + เควสต์ดนตรีที่สถานี
4. **S4 ด่าน C ดาวแก๊ส + ด่าน D ดาวฤกษ์**
5. **S5 แผนที่อวกาศ + ปรับสมดุล** ใช้ usage rows `adv:*` ดูว่าผู้เล่นตายตรงไหนก่อนปรับตัวเลข

## 8. คำถามเปิดให้เจ้าของเสริม
- ยานคุมแบบไหนดีที่สุดบนมือถือ: ปุ่มลูกศร (ตอนนี้) หรือลากนิ้วนำยาน?
- อยากให้แร่มีกี่ชนิด และแต่ละชนิด "ใช้ทำอะไร" นอกจากขายเป็นเหรียญ (เช่นปลดสกินยาน/อาณานิคม)?
- ด่านดาวฤกษ์ควรมี "บอส" เป็นสิ่งมีชีวิตพลังงานไหม?
- หนังต้องมีเสียงบรรยาย (voice-over) ไหม — ตอนนี้ยังไม่มีเอนจินเสียงสำหรับเรื่องนี้ (มีแค่ซับไตเติล)
- ลำดับด่านเปิดตามเส้น `req` เดิม หรือให้เล่นอิสระในแผนที่อวกาศ?

## 9. ความเสี่ยง/สิ่งที่ยังไม่รู้
- ทุกอย่างยังไม่เคยเล่นบนมือถือจริง (fps, การคุมยาน, เสียง, หนัง)
- เกมยานทำงานบนแคนวาสเดียวกับด่านเดิม ต้องวัด fps บนเครื่องรุ่นล่างก่อนเพิ่มศัตรู/อนุภาค
- ตัวเลขสมดุล (เวลาเรือแม่ 55 วินาที, HP ศัตรู, มูลค่าแร่) เป็นการเดาที่ต้องปรับจากข้อมูลจริง
