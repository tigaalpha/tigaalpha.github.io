The First Read and the Practised Run: Two Different Jobs at the Piano

Practice tips · 2026-11-12

A first read at the piano is a careful first meeting with a page: slow enough to be mostly accurate, curious about the shape of the piece, and honest about what is not yet known. A practised run is a later, continuous playing of a section or a whole piece, used as a check after detailed work. Mixing the two jobs — trying to "perform" a page on the first day, or always stopping in a practised run to tinker — makes both jobs less useful.

What a first read is for

The first read is for orientation. You want to feel the metre, find the main line, notice repeats, and discover which bars will need slow work. It is not for a high tempo, and it is not a test of whether you are already "good at the piece." A steady, modest speed, with a few calm stops to mark a problem, is enough.

If you can look a bar ahead, do so. If looking ahead makes the current bar fall apart, return to a slower speed and a smaller span. The first read should leave you with a marked score and a short list of corners, not with a vague feeling that the piece is either easy or impossible.

How to end a first read well

Stop while attention is still clear. Write down the bars that broke, the fingering that felt doubtful, and any rhythm you faked. A first read that ends with no marks is usually a first read that will be forgotten. You do not need a long essay in the margin; a few honest ticks are enough.

Then leave the piece, or move to slow work on one marked corner. Immediately repeating a messy first read at a faster speed only practises the mess.

What a practised run is for

A practised run is a later check: can this section, or this piece, go on in time, with the planned fingering and with fewer stops? It should happen after the corners have been practised slowly, not instead of that work. Choose a tempo that is close to the one you want, or a little under it, and decide in advance whether you will stop for a serious slip or keep going and mark the slip afterwards.

A compact way to use a run:

  • Name the span (one section, one page, or the whole piece).
  • Name the tempo, and stay there.
  • Play through according to the stop rule you chose.
  • Mark what broke, then leave the run and repair those bars slowly.
  • Do not stack three disappointed runs in a row without repair.

Why the two jobs should stay distinct

If every session is a hoped-for performance, difficult bars never receive the slow work they need. If every session is only slow repair, you may not discover how the sections join, or how stamina and page turns feel. A simple weekly plan can hold both: first reads and slow repair on some days, a practised run at the end of a week, then more repair.

Mood and honesty

A first read can feel clumsy; that is normal. A practised run can feel exposed; that is also normal. The useful habit is to describe what happened in the score, not to judge the whole day by one page. If a run goes poorly, shorten the span next time and return to slow work sooner.

FAQ

Q: How slow should a first read be?

A: Slow enough that most pitches and rhythms are honest. If you are inventing large stretches of the page, go slower or read a smaller span.

Q: Should I stop during a practised run?

A: Decide before you start. For a check of continuity, keep going and mark slips. For a check of a fragile corner, a single planned stop can be fine.

Q: Can I do a practised run on the first day?

A: A short, modest run of a tiny span can be a check, but it should not replace a careful first read and slow work.

Q: What if I always rush the second half of a run?

A: Practise the second half alone, then start a run from the middle, then from the beginning. The end of a piece needs its own attention.

Q: How often should I run a piece?

A: Often enough to learn how it joins, not so often that you skip repair. A run is a check after work, not a substitute for work.
