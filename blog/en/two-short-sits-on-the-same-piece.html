Two Short Practice Sits on the Same Piano Piece

Practice tips · 2026-11-12

A long sitting on one piece often starts well and then wanders: the same bars are repeated without a plan, or new pages are opened because the first ones feel tired. Two short sits on the same piece, separated by a break, give the hands a chance to return to a written aim while they are still fresh. The method is simple, but it only works if both sits are planned, and if the second sit does not become a vague run-through of the whole movement.

Give the first sit a small, written aim

Before you begin, write one job in the score: a phrase to loop, a tempo, a fingering seam, or a pedal change. Work only on that job for a modest stretch of time, then stop while the playing is still controlled. Do not "use up" the remaining minutes by raking through later pages. Leave the score open at the same place, with the aim still visible, so the second sit can start without a hunt.

Take a real break, then begin the second sit from the same bars

Stand, look at something else, or work on a different piece, then return. The second sit should begin with the same bars, at the same or a slightly more flowing tempo, and should ask whether the aim now holds. If it does, you may extend a little on either side of the phrase. If it does not, stay with the original loop rather than adding new work. The value of the break is a clearer second look, not a chance to change the agenda.

What not to do in the second sit

Do not raise the tempo far beyond the first sit in a single jump. Do not add a new technical problem from later in the piece. Do not play a full run as a test unless the written aim was that run. A full run can be a third, later event, or a task for another day. The two-sit plan is for deepening one place, not for covering the whole work twice.

A short take in TIGA ALPHA at the end of the second sit can capture whether the same bars now sit more calmly, provided you compare it with the aim you wrote, not with a general wish to play more.

Using the plan in a busy week

On a short day, two sits of modest length still outweigh one tired marathon. If only one sit is possible, keep it as the "first sit" and make the next day's first job the "second sit" on the same bars. Teachers can also assign this shape: one aim, two visits, a brief note of what changed. The piece then has a memory of work, not only of time spent at the piano.

  • Write one aim for the first sit and stop while the work is still controlled.
  • Leave the score marked at the same bars.
  • After a break, start the second sit on those bars, not at the beginning of the piece unless that is the aim.
  • If the aim holds, widen the window slightly; if it does not, loop the original bars again.
  • Note what changed between the two sits, in a few words, for the next day.

FAQ

Q: How long should each sit be?

A: Long enough to work the aim carefully, short enough that the playing stays controlled. The exact minutes will vary with age and with the piece.

Q: Can the second sit be later in the same day?

A: Yes. A gap of some hours can work as well as a gap of some minutes, so long as you return to the same marked bars.

Q: What if I want to use the second sit for a different piece?

A: Then you no longer have this plan. The point is a second visit to the same work. Another piece can have its own pair of sits.

Q: Should a complete run occupy the second sit?

A: Only if the written aim was that run. Otherwise the run can wait, and the second sit should test the original bars.

Q: How do I remember what the first sit achieved?

A: A few words in the score or in a notebook, plus the unmoved marks on the page, are enough. The second sit then has a starting point.
