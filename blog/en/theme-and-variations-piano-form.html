Theme and Variations on Piano: How One Tune Keeps Changing

Songs · 2026-11-12

A theme-and-variations set on the piano begins with a clear tune, or a clear harmonic plan, and then presents a series of variations in which that idea is decorated, reharmonised, moved to another register, or given a new rhythm, while remaining recognisable. The listener’s pleasure is in hearing both the new surface and the familiar idea underneath. The player’s work is to know the theme well enough to keep pointing to it.

Learning the theme as a source, not as a short preface

The theme should be learned thoroughly: melody, bass, inner harmony, phrase lengths, and a simple dynamic shape. It is not a brief introduction to be skimmed on the way to "the interesting parts." If the theme is vague in your ear, later variations will feel like separate short pieces, and the set will lose its centre.

Sing the theme, play the melody alone, play the bass alone, then put the texture together. Mark the phrase lengths, especially if the theme is an eight-bar or sixteen-bar design that later variations will keep.

Hearing what each variation changes

For each variation, write a short label in the score: "melody in the left hand," "syncopated rhythm," "minor colour," "running figuration," "quiet chorale." The label should name the main change, not every detail. Then play the theme and that variation in a pair, asking whether the theme’s phrase lengths and main cadences are still there.

Even in a busy variation, a listener should be able to follow something from the theme — a melody in outline, a bass plan, or the pattern of cadences. If you cannot point to that thread, slow down and find it before you add speed or extra colour.

Practising a set without always starting at variation one

It is useful to start some sessions with a later variation, then play the theme afterward as a reminder, then return to the later variation. It is also useful, near a performance, to play the whole set in order, with the planned pauses, so the contrasts of tempo and character are honest. Daily work that only ever begins at the first bar of the theme can leave the last variations under-rehearsed.

Tempo, character and the close of the set

The last pages must still feel like one work

Variations often change tempo and character, but the set still needs a sense of one work. A very fast variation should still allow the theme’s outline to be heard. A very slow one should not lose the phrase lengths. The last variation, or a closing return of the theme, should feel like an ending, not like another middle. Practise the last two sections as a pair, including the silence you want after the final chord.

A compact plan for a variations set

  • Learn the theme in melody, bass and harmony.
  • Label the main change in each variation.
  • Practise theme plus one variation as a pair, often.
  • Start some sessions in a later variation, then remind yourself of the theme.
  • Run longer spans in order when the contrasts need a check.

FAQ

Q: Do I have to play every variation in a published set?

A: For study, a teacher may assign a selection. For a performance of a complete published set, follow the intended sequence unless a clear, agreed cut has been made.

Q: What if a variation hides the melody almost completely?

A: Look for the bass plan or the cadence pattern. There is usually still a thread. Mark it and bring it out just enough to be followed.

Q: Should all variations stay in the same key?

A: Many do, with perhaps one in the minor or a neighbouring key. Read the key of each variation and mark it, so a change is not a surprise in performance.

Q: How do I stop the set from sounding like a list of exercises?

A: Name a character for each variation, keep the theme’s phrase lengths, and plan the contrasts of tempo and silence, especially toward the close.

Q: Is it useful to write the theme’s melody above a difficult variation?

A: A light cue can help in study. Remove anything that clutters a performance copy once the thread is secure.
