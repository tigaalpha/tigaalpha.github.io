도레미, 알파벳, 다라마 음이름 정리

음악 이론 · 2026-11-14

피아노의 같은 건반을 부르는 이름은 쓰는 상황에 따라 세 가지가 있어요. 노래하듯 부르는 도레미, 코드와 조 이름에 쓰는 C·D·E 같은 알파벳 이름, 그리고 한국 음악 교과서에서 조 이름을 말할 때 쓰는 다라마예요. 예를 들어 가운데 도는 C이고, 한국어 음이름으로는 다라고 불러요. 그래서 C장조는 다장조, G장조는 사장조라고도 해요. 처음 배우는 학생들은 레슨에서는 도레미, 코드 악보에서는 알파벳 이름, 학교 수업에서는 다장조를 만나 헷갈려하기 쉬워요. 세 이름 체계의 관계와 쓰임새를 한 번 정리해 두면 악보와 설명을 훨씬 편하게 읽을 수 있어요. 이 글에서는 각 체계의 대응 관계, 고정도와 이동도의 차이, 올림과 내림 표기, 그리고 상황별 쓰임새를 정리해 볼게요.

세 이름 한눈에 보기

  • 도 = C = 다
  • 레 = D = 라
  • 미 = E = 마
  • 파 = F = 바
  • 솔 = G = 사
  • 라 = A = 가
  • 시 = B = 나

외우는 요령

알파벳 쪽은 알파벳 순서가 A부터 시작해 라가 A라는 점을 기억하면 쉬워요. 다라마 쪽은 가나다 순서가 라에서 시작해요.

고정도와 이동도

고정도

도를 언제나 C 건반으로 고정해 부르는 방식이에요. 어떤 조의 곡이든 C 건반은 도예요.

이동도

곡의 으뜸음을 도로 삼아 부르는 방식이에요. 사장조라면 G 건반을 도로 불러요.

쓰임의 차이

고정도는 건반 위치를 익히는 데 편하고, 이동도는 음의 역할과 관계를 느끼는 데 좋아요.

올림과 내림 표기

알파벳 체계

올림표는 #, 내림표는 ♭을 붙여 C#, B♭처럼 적어요.

다라마 체계

올림은 "올림", 내림은 "내림"을 앞에 붙여 올림다, 내림나처럼 말해요. 그래서 B♭장조는 내림나장조예요.

도레미 체계

"도 샵", "시 플랫"처럼 말하는 경우가 많아요.

조 이름 읽기

  • C장조 = 다장조
  • G장조 = 사장조
  • F장조 = 바장조
  • A단조 = 가단조
  • E단조 = 마단조
  • D장조 = 라장조

교과서나 해설에서 "라장조"를 보면 레 음을 으뜸음으로 하는 장조라는 뜻이에요. 계이름의 라와 헷갈리지 않도록 주의해요.

상황별 쓰임새

레슨과 노래

선율을 부르거나 손가락으로 짚을 때는 도레미가 편해요.

코드 악보와 리드시트

코드 이름은 C, Am, G7처럼 알파벳 이름으로 적어요.

곡 제목과 해설

클래식 곡 제목은 다장조, 사단조처럼 다라마로 소개되는 경우가 많아요.

헷갈리기 쉬운 곳

라와 라

계이름의 라는 A 건반이지만, 한국어 음이름의 라는 D 건반이에요. 같은 글자가 다른 음을 가리켜요.

가와 나

한국어 음이름 가는 A, 나는 B예요. 가나다 순서가 가에서 시작한다고 도에서 시작하는 것은 아니에요.

연습 놀이

이름 바꿔 말하기

건반 하나를 누르고 세 가지 이름을 차례로 말해 보는 놀이를 해요.

카드 짝 맞추기

도레미 카드, 알파벳 카드, 다라마 카드를 섞어 같은 음끼리 짝을 맞춰요.

곡 제목 읽기

좋아하는 클래식 곡 제목의 조 이름을 알파벳 이름으로 바꿔 말해 봐요.

세 이름을 번갈아 말하며 건반을 누르는 놀이는 TIGA ALPHA의 화면 건반으로 해 보면, 누른 음이 맞는지 음 피드백으로 바로 확인돼요.

자주 묻는 질문

Q: 왜 라가 A인가요?

A: 알파벳 음이름은 오래전부터 라 음을 기준으로 A부터 붙여 온 방식이라 그래요.

Q: 다라마 이름은 언제 쓰나요?

A: 주로 조 이름을 말할 때 써요. 건반 하나하나를 부를 때는 도레미나 알파벳 이름이 더 흔해요.

Q: 아이에게는 무엇부터 가르치나요?

A: 먼저 도레미로 건반에 익숙해진 뒤, 코드 악보를 볼 때 알파벳 이름을 더하는 순서가 무난해요.

Q: 이동도로 부르면 헷갈리지 않나요?

A: 처음엔 낯설지만 조가 바뀌어도 음의 역할을 같은 이름으로 느낄 수 있는 장점이 있어요.
